# API Key Management

This page explains how to create, use, and protect AIhub API keys.

---

## What an API key is

An API key is the credential used to identify and authorize requests to AIhub. Each key is tied to a model group and can only access the models in that group.

---

## Create a key

1. Log in to the AIhub console
2. Open the API Key management page
3. Click create key
4. Fill in the key name and group
5. Optionally set an expiration time
6. Save the key and copy it immediately

---

## Key fields

- **Name**: a human-readable label for the key
- **Group**: the model group the key can access
- **Expiration**: optional validity period

---

## Usage notes

- Use one key per application or environment when possible
- Store keys in environment variables or secret managers
- Avoid putting keys directly into source code or shared config files

---

## Rotate or revoke a key

Reset or revoke a key immediately if:

- It is accidentally exposed
- It has been committed to a repository
- It is no longer needed
- You suspect unauthorized access

---

## Troubleshooting

### Key cannot be used

Check whether:

- The key is active
- The key has access to the requested model
- The request header uses `Authorization: Bearer <key>`

### Key expired

Create a new key and update the client configuration.
