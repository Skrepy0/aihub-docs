# AIhub 使用指南

AIhub 是基于 [new-api](https://docs.newapi.pro) 的 AI 服务中转平台。通过 AIhub，可以使用统一的 API Key 和 OpenAI 兼容接口调用多种 AI 模型。

首次使用者，建议按以下顺序阅读本文档：

1. 了解 AIhub 的基本功能与定位
2. 创建并获取 API Key
3. 在客户端或代码中配置 Key 和 Base URL
4. 使用示例请求进行测试
5. 遇到问题时查阅常见问题章节

---

## AIhub 概述

AIhub 提供以下核心能力：

- 统一的 AI 接口入口，聚合多种模型服务
- 单套 API Key 可复用至多个工具、应用和脚本
- 完全兼容 OpenAI API 风格，降低接入成本

若已使用过 OpenAI 兼容接口，接入 AIhub 仅需替换三个配置项：

- `API Key`
- `Base URL`
- `model`

---

## 快速开始

### 登录 AIhub

访问 [AIhub](https://aihub.skrepy.dpdns.org/) 并完成注册登录。

### 创建 API Key

进入 [API Key 管理页面](https://aihub.skrepy.dpdns.org/keys)，点击创建新密钥，填写以下信息：

- 名称：自定义标识，便于区分不同应用
- 分组：选择该 Key 可调用的模型分组
- 过期时间（可选）：可设置有效期，留空表示永久有效

> 每个 API Key 仅能调用所在分组内的模型。创建时请确认分组选择正确。

### 记录接口地址

AIhub 服务端地址（Base URL）如下，后续配置中需统一使用：

```text
https://aihub.skrepy.dpdns.org
```

### 选择模型

在客户端或代码中需要指定模型名称时，请确保所选模型在当前 Key 的分组权限范围内。

可在 [模型广场](https://aihub.skrepy.dpdns.org/pricing) 中按分组筛选，查看可用的模型列表。

---

## API Key 配置方式

API Key 是调用 AIhub 服务的身份凭证。每次请求需同时提供以下三项：

- `API Key`：认证凭证
- `Base URL`：服务端地址
- `model`：目标模型名称

### 在第三方客户端中配置

支持 OpenAI 兼容协议的客户端通常提供以下配置字段：

- **API Key**：填入 AIhub 创建的 Key
- **Base URL**：填入 `https://aihub.skrepy.dpdns.org`
- **Model**：填入可用模型名称

### 在代码中配置

推荐通过环境变量注入，避免将 Key 硬编码到源码中：

```bash
AIHUB_API_KEY=sk-xxxxxx
AIHUB_BASE_URL=https://aihub.skrepy.dpdns.org
```

程序运行时从环境变量读取上述配置。

## 请求示例

以下示例均使用 OpenAI 兼容接口格式，需替换其中的 `Base URL`、`API Key` 和 `model` 为实际值。

### curl

```bash
curl https://aihub.skrepy.dpdns.org/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": "你好，你是什么模型"
      }
    ]
  }'
```

### JavaScript (Node.js)

```javascript
const response = await fetch('https://aihub.skrepy.dpdns.org/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    Authorization: `Bearer ${process.env.AIHUB_API_KEY}`,
  },
  body: JSON.stringify({
    model: 'gpt-4o-mini',
    messages: [{ role: 'user', content: '你好，你是什么模型' }],
  }),
});

const data = await response.json();
console.log(data);
```

### Python

```python
import os
import requests

url = "https://aihub.skrepy.dpdns.org/v1/chat/completions"
headers = {
    "Authorization": f"Bearer {os.getenv('AIHUB_API_KEY')}",
    "Content-Type": "application/json",
}
body = {
    "model": "gpt-4o-mini",
    "messages": [
        {"role": "user", "content": "你好，你是什么模型"}
    ],
}

response = requests.post(url, headers=headers, json=body)
print(response.json())
```

## 客户端配置说明

使用 OpenAI 兼容客户端时，通常只需填写三个字段：

- `API Key`：AIhub 创建的 Key
- `Base URL`：`https://aihub.skrepy.dpdns.org`
- `Model`：可用模型名称

### 常见字段名称对照

不同客户端对配置项的命名可能存在差异，常见变体如下：

| 实际含义 | 常见字段名                                  |
| -------- | ------------------------------------------- |
| API Key  | API Key / Key / Token / API Token           |
| Base URL | Base URL / API Base / Endpoint / Server URL |
| Model    | Model / Model Name                          |

### 验证配置

配置完成后，发送一条简单消息进行测试，例如：

> 你好

若能正常返回响应，则配置成功。

## 常见问题

### 401 Unauthorized

**原因**：

- API Key 填写错误或已失效
- 请求头未包含 `Authorization: Bearer <key>`

**处理**：重新复制 Key，确认请求头格式正确。

### 403 Forbidden

**原因**：

- 当前 Key 无权访问指定模型
- 账号权限不足

**处理**：检查模型名称是否在分组权限内，或更换可用模型。

### 429 Too Many Requests

**原因**：请求频率超过限制。

**处理**：降低请求频率，增加重试间隔，检查是否存在异常循环调用。

### 模型不存在或不可用

**原因**：

- `model` 参数拼写错误
- 模型已下线
- 当前 Key 未开通该模型权限

**处理**：在模型广场确认可用模型列表，更换正确名称。

### 客户端连接失败

**原因**：

- Base URL 填写错误
- 网络无法访问 AIhub 服务
- 客户端不支持 OpenAI 兼容协议

**处理**：确认 Base URL 为 `https://aihub.skrepy.dpdns.org`，使用 curl 验证服务可用性，检查客户端文档。

## 安全建议

API Key 属于敏感凭证，请遵守以下规则：

- 禁止提交至公开或私有 Git 仓库
- 禁止通过截图、录屏等方式公开传播
- 禁止硬编码在前端代码或客户端可反编译的文件中
- 怀疑泄露时立即重置 Key
