# AIhub User Guide

AIhub is an AI service relay platform based on [new-api](https://docs.newapi.pro). Through AIhub, you can call multiple AI models using a unified API Key and an OpenAI‑compatible interface.

For first‑time users, we recommend reading this document in the following order:

1. Understand the basic functions and positioning of AIhub
2. Create and obtain an API Key
3. Configure the Key and Base URL in your client or code
4. Test with example requests
5. Refer to the FAQ section if you encounter issues

---

## AIhub Overview

AIhub provides the following core capabilities:

- A unified AI interface entry point that aggregates multiple model services
- A single API Key reusable across multiple tools, applications, and scripts
- Full compatibility with the OpenAI API style, reducing integration costs

If you have used an OpenAI‑compatible interface before, connecting to AIhub only requires replacing three configuration items:

- `API Key`
- `Base URL`
- `model`

---

## Quick Start

### Log in to AIhub

Visit [AIhub](https://aihub.skrepy.dpdns.org/) and complete registration and login.

### Create an API Key

Go to the [API Key Management page](https://aihub.skrepy.dpdns.org/keys) and click to create a new key. Fill in the following information:

- Name: a custom identifier to distinguish different applications
- Group: select the model group that this Key can call
- Expiration time (optional): can set a validity period; leave blank for permanent validity

> Each API Key can only call models within its assigned group. Please confirm the group selection is correct when creating.

### Note the Endpoint Address

The AIhub server address (Base URL) is as follows, and must be used consistently in subsequent configurations:

```text
https://aihub.skrepy.dpdns.org
```

### Choose a Model

When specifying a model name in your client or code, ensure that the selected model is within the permission scope of the Key's group.

You can filter by group in the [Model Marketplace](https://aihub.skrepy.dpdns.org/pricing) to view the list of available models.

## API Key Configuration

The API Key is the identity credential for calling AIhub services. Each request must provide the following three items:

- `API Key`: authentication credential
- `Base URL`: server address
- `model`: target model name

### Configuring in Third‑Party Clients

Clients that support the OpenAI‑compatible protocol usually provide the following configuration fields:

- **API Key**: enter the Key created in AIhub
- **Base URL**: enter `https://aihub.skrepy.dpdns.org`
- **Model**: enter the available model name

### Configuring in Code

It is recommended to inject the Key via environment variables to avoid hard‑coding it in source code:

```bash
AIHUB_API_KEY=sk-xxxxxx
AIHUB_BASE_URL=https://aihub.skrepy.dpdns.org
```

The program reads the above configuration from environment variables at runtime.

## Request Examples

The following examples use the OpenAI‑compatible interface format. Replace the `Base URL`, `API Key`, and `model` with actual values.

### curl

```bash
curl https://aihub.skrepy.dpdns.org/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": "Hello, what model are you?"
      }
    ]
  }'
```

### JavaScript (Node.js)

```javascript
const response = await fetch('https://aihub.skrepy.dpdns.org/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    Authorization: `Bearer ${process.env.AIHUB_API_KEY}`,
  },
  body: JSON.stringify({
    model: 'gpt-4o-mini',
    messages: [{ role: 'user', content: 'Hello, what model are you?' }],
  }),
});

const data = await response.json();
console.log(data);
```

### Python

```python
import os
import requests

url = "https://aihub.skrepy.dpdns.org/v1/chat/completions"
headers = {
    "Authorization": f"Bearer {os.getenv('AIHUB_API_KEY')}",
    "Content-Type": "application/json",
}
body = {
    "model": "gpt-4o-mini",
    "messages": [
        {"role": "user", "content": "Hello, what model are you?"}
    ],
}

response = requests.post(url, headers=headers, json=body)
print(response.json())
```

## Client Configuration Notes

When using an OpenAI‑compatible client, you typically only need to fill in three fields:

- `API Key`: the Key created in AIhub
- `Base URL`: `https://aihub.skrepy.dpdns.org`
- `Model`: the available model name

### Common Field Name Mapping

Different clients may use different names for these configuration items. Common variations include:

| Actual meaning | Common field names                          |
| -------------- | ------------------------------------------- |
| API Key        | API Key / Key / Token / API Token           |
| Base URL       | Base URL / API Base / Endpoint / Server URL |
| Model          | Model / Model Name                          |

### Verifying Configuration

After configuration, send a simple test message, for example:

> Hello

If you receive a normal response, the configuration is successful.

## Frequently Asked Questions

### 401 Unauthorized

**Cause**:

- API Key is incorrect or has expired
- Request header missing `Authorization: Bearer <key>`

**Solution**: Recopy the Key and confirm the request header format is correct.

### 403 Forbidden

**Cause**:

- Current Key does not have permission to access the specified model
- Account permissions are insufficient

**Solution**: Check whether the model name is within the group permissions, or switch to an available model.

### 429 Too Many Requests

**Cause**: Request frequency exceeds the limit.

**Solution**: Reduce request frequency, increase retry intervals, and check for abnormal loop calls.

### Model does not exist or is unavailable

**Cause**:

- Misspelling in the `model` parameter
- Model has been deprecated
- Current Key does not have permission for that model

**Solution**: Confirm the list of available models in the Model Marketplace and use the correct name.

### Client connection failure

**Cause**:

- Base URL is incorrect
- Network cannot reach AIhub service
- Client does not support OpenAI‑compatible protocol

**Solution**: Confirm the Base URL is `https://aihub.skrepy.dpdns.org`, use curl to verify service availability, and check client documentation.

## Security Recommendations

API Keys are sensitive credentials. Please adhere to the following rules:

- Do not commit them to public or private Git repositories
- Do not publicly share them via screenshots, screen recordings, etc.
- Do not hard‑code them in frontend code or client‑side decompilable files
- Reset the Key immediately if you suspect it has been leaked
