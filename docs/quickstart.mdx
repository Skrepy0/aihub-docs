# AIhub Quick Start

This document guides you through the complete process from zero to your first successful call to the AIhub API. After reading, you should be able to:

- Obtain a valid API Key
- Configure the correct server address
- Successfully send and receive your first request response

---

## Prerequisites

The AIhub integration process consists of four basic steps:

1. Log in to the [AIhub](https://aihub.skrepy.dpdns.org) console
2. Create an [API Key](https://aihub.skrepy.dpdns.org/keys)
3. Configure the Key and Base URL in your client or code
4. Select an available model and send a test request

Two core configuration values:

- **API Key**: identity credential for authenticating the requester
- **Base URL**: server address specifying the request target

AIhub server endpoint:

```text
https://aihub.skrepy.dpdns.org/
```

This address applies to all OpenAI‑compatible clients and example code.

---

## Creating an API Key

[Click here to go to the API Key page](https://aihub.skrepy.dpdns.org/keys)

After logging in to the AIhub console, go to the API Key management page and click "Create API Key". The page provides the following action options:

- Copy the Key string
- Edit key information
- Disable the Key (temporary freeze)

### Post‑Creation Precautions

After the key is generated, do not paste the key directly into chat tools, forums, or share it via screenshots.

### When to Reset a Key

You should reset the Key immediately in the following situations:

- The Key has been exposed in chat logs, emails, or public documents
- The Key has been committed to a code repository (including private repositories)
- You suspect that someone else has obtained the Key
- The current runtime environment is no longer trusted (e.g., server migration, personnel changes)

## Base URL Configuration Notes

Different clients may use different field names for the server address. Common names include:

- Base URL
- API Base
- Endpoint
- Server URL

Regardless of the field name, always enter:

```text
https://aihub.skrepy.dpdns.org/
```

### Common Configuration Mistakes

- Entering only the domain name without the required API path prefix
- Including extra spaces or line breaks when copying
- Using an incorrect test address or an obsolete old address
- Adding extra path segments at the end (other than the standard `/v1`)

## API Key Configuration Location

### Third‑Party Clients

Clients that support the OpenAI‑compatible protocol usually provide the following configuration fields:

| Field    | Value                             |
| -------- | --------------------------------- |
| API Key  | AIhub‑created Key                 |
| Base URL | `https://aihub.skrepy.dpdns.org/` |
| Model    | Available model name              |

### Configuring in Code

It is recommended to inject the Key via environment variables to avoid hard‑coding:

```bash
AIHUB_API_KEY=sk-xxxxxx
AIHUB_BASE_URL=https://aihub.skrepy.dpdns.org/
```

Example of reading in code (Node.js):

```javascript
const apiKey = process.env.AIHUB_API_KEY;
const baseUrl = process.env.AIHUB_BASE_URL;
```

### Servers and Deployment Platforms

On cloud servers, container environments, or online deployment platforms, you should store the Key and Base URL in the platform's environment variable or secret management feature, rather than writing them into configuration files.

## Making Your First Request

The following examples are minimal working calls. Replace the placeholders:

- `YOUR_API_KEY`: the actual API Key you created
- `model`: a model name that your Key has permission to call

### curl

```bash
curl https://aihub.skrepy.dpdns.org/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": "Hello, what model are you?"
      }
    ]
  }'
```

### JavaScript (Node.js)

```javascript
const response = await fetch('https://aihub.skrepy.dpdns.org/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    Authorization: `Bearer ${process.env.AIHUB_API_KEY}`,
  },
  body: JSON.stringify({
    model: 'gpt-4o-mini',
    messages: [{ role: 'user', content: 'Hello, what model are you?' }],
  }),
});

const data = await response.json();
console.log(data);
```

### Python

```python
import os
import requests

url = "https://aihub.skrepy.dpdns.org/v1/chat/completions"
headers = {
    "Authorization": f"Bearer {os.getenv('AIHUB_API_KEY')}",
    "Content-Type": "application/json",
}
body = {
    "model": "gpt-4o-mini",
    "messages": [
        {"role": "user", "content": "Hello, what model are you?"}
    ],
}

response = requests.post(url, headers=headers, json=body)
print(response.json())
```

## Troubleshooting

### 401 Unauthorized

Check the following:

- Is the API Key copied completely without extra spaces or line breaks?
- Does the request header include `Authorization: Bearer <key>`?
- Has the Key been reset or disabled?

### 403 Forbidden

Check the following:

- Does the current Key have permission to access the requested model?
- Is the model name within the group permission scope?

### 429 Too Many Requests

Check the following:

- Have you sent too many requests in a short time?
- Is there a loop call or overly aggressive retry logic in the code?

### Client Connection Failure

Check the following:

- Is the Base URL `https://aihub.skrepy.dpdns.org/`?
- Does the client support the OpenAI‑compatible protocol?
- Can the current network access this domain?
