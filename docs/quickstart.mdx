# AIhub Quick Start

This guide walks you through the full process of making your first successful AIhub API call. After reading it, you should be able to:

- Obtain a valid API key
- Configure the correct server address
- Send your first request and receive a response

---

## Preparation

The AIhub integration flow has four basic steps:

1. Log in to the [AIhub](https://aihub.skrepy.dpdns.org) console
2. Create an [API key](https://aihub.skrepy.dpdns.org/keys)
3. Configure the key and Base URL in your client or code
4. Select an available model and send a test request

The two core values are:

- **API Key**: the credential used to authenticate requests
- **Base URL**: the server address that defines the request target

AIhub server address:

```text
https://aihub.skrepy.dpdns.org/
```

This address works for all OpenAI-compatible clients and sample code.

---

## Create an API key

[Go to the API key page](https://aihub.skrepy.dpdns.org/keys)

After logging in, open the API key management page and click create. The page supports the following actions:

- Copy the key string
- Edit key details
- Disable the key temporarily

### After creating a key

Do not paste the key directly into chat tools, forums, or screenshots.

### When to reset a key

Reset the key immediately if any of the following happens:

- The key is exposed in chat logs, emails, or public docs
- The key is committed to a repository, including private repositories
- You suspect someone else has obtained the key
- The current environment is no longer trustworthy, such as after a server migration or personnel change

---

## Base URL configuration

Different clients may name the server address field differently. Common labels include:

- Base URL
- API Base
- Endpoint
- Server URL

No matter what the label is, fill in:

```text
https://aihub.skrepy.dpdns.org/
```

### Common mistakes

- Filling only the domain and forgetting the path prefix
- Including extra spaces or line breaks while copying
- Using an outdated test address
- Appending an extra path segment beyond the standard `/v1`

## API key placement

### Third-party clients

OpenAI-compatible clients usually provide the following fields:

| Field    | Value                             |
| -------- | --------------------------------- |
| API Key  | The AIhub key                     |
| Base URL | `https://aihub.skrepy.dpdns.org/` |
| Model    | A valid model name                |

### In code

We recommend injecting values through environment variables:

```bash
AIHUB_API_KEY=sk-xxxxxx
AIHUB_BASE_URL=https://aihub.skrepy.dpdns.org/
```

Node.js example:

```javascript
const apiKey = process.env.AIHUB_API_KEY;
const baseUrl = process.env.AIHUB_BASE_URL;
```

### Servers and deployment platforms

On cloud servers, containers, or hosted deployment platforms, store the key and Base URL in the platform's environment variables or secret manager instead of writing them into config files.

## Make your first request

The following examples show the minimum viable call. Replace the placeholders with real values:

- `YOUR_API_KEY`: your actual API key
- `model`: a model name the current key is allowed to use

### curl

```bash
curl https://aihub.skrepy.dpdns.org/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": "Hello, what model are you?"
      }
    ]
  }'
```

### JavaScript (Node.js)

```javascript
const response = await fetch('https://aihub.skrepy.dpdns.org/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    Authorization: `Bearer ${process.env.AIHUB_API_KEY}`,
  },
  body: JSON.stringify({
    model: 'gpt-4o-mini',
    messages: [{ role: 'user', content: 'Hello, what model are you?' }],
  }),
});

const data = await response.json();
console.log(data);
```

### Python

```python
import os
import requests

url = "https://aihub.skrepy.dpdns.org/v1/chat/completions"
headers = {
    "Authorization": f"Bearer ${os.getenv('AIHUB_API_KEY')}",
    "Content-Type": "application/json",
}
body = {
    "model": "gpt-4o-mini",
    "messages": [
        {"role": "user", "content": "Hello, what model are you?"}
    ],
}

response = requests.post(url, headers=headers, json=body)
print(response.json())
```

After configuration, send a simple test message:

- The API key is valid

## Troubleshooting

### 401 Unauthorized

Check the following:

- The API key was copied completely without extra spaces or line breaks
- The request header includes `Authorization: Bearer <key>`
- The key has not been reset or disabled

### 403 Forbidden

Check the following:

- The current key has permission for the requested model
- The model name is within the group permissions

### 429 Too Many Requests

Check the following:

- Too many requests were sent in a short period of time
- The code has a loop or retry policy that is too aggressive

### Client connection failed

Check the following:

- The Base URL is `https://aihub.skrepy.dpdns.org/`
- The client supports the OpenAI-compatible protocol
- The current network can reach the domain
