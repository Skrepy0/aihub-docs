# 常见问题

## 401 Unauthorized

**可能原因**：

- API Key 不正确或已过期
- 请求头缺少 `Authorization: Bearer <key>`

**处理**：重新复制 Key，并确认请求头格式正确。

## 403 Forbidden

**可能原因**：

- 当前 Key 无法访问目标模型
- 账号权限不足

**处理**：检查模型是否在 Key 的分组内，或切换到可用模型。

## 429 Too Many Requests

**可能原因**：请求频率过高。

**处理**：降低请求频率、增加重试间隔，并检查是否存在意外循环。

## 模型不存在或不可用

**可能原因**：

- `model` 名称拼写错误
- 模型已下线
- 当前 Key 没有该模型权限

**处理**：在模型列表中确认可用模型，并使用正确名称。

## 客户端连接失败

**可能原因**：

- Base URL 配置错误
- 网络无法访问 AIhub
- 客户端不支持 OpenAI 兼容协议

**处理**：确认 Base URL 为 `https://aihub.skrepy.dpdns.org`，用 curl 验证连通性，并检查客户端文档。

## 可以多个应用共用一个 Key 吗？

可以，但更建议为不同应用创建不同 Key，便于单独吊销和管理。

## 应该使用哪个 Base URL？

通用 API 调用可使用 `https://aihub.skrepy.dpdns.org`。部分客户端要求加上 `/v1` 后缀。

---

## 安全提示

- 不要在公开场合分享 Key
- 一旦怀疑泄露，立即重置 Key
- 不要把 Key 放进前端打包产物或客户端源码中
