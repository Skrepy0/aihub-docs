# API Key 管理

本文档介绍如何创建、使用和保护 AIhub API Key。

---

## 什么是 API Key

API Key 是用于标识和授权访问 AIhub 的凭证。每个 Key 绑定一个模型分组，只能访问该分组下的模型。

---

## 创建 Key

1. 登录 AIhub 控制台
2. 进入 API Key 管理页面
3. 点击创建 Key
4. 填写 Key 名称和分组
5. 可选设置过期时间
6. 保存并立即复制 Key

---

## Key 字段说明

- **名称**：便于识别的标签
- **分组**：该 Key 可访问的模型分组
- **过期时间**：可选的有效期

---

## 使用建议

- 尽量为不同应用或不同环境创建独立 Key
- 将 Key 存放在环境变量或 Secret 管理器中
- 避免把 Key 直接写入源码或共享配置文件

---

## 轮换或吊销 Key

如果出现以下情况，请立即重置或吊销 Key：

- Key 被意外暴露
- Key 被提交到仓库
- Key 已经不再需要
- 怀疑存在未授权访问

---

## 常见问题

### Key 无法使用

请检查：

- Key 是否处于启用状态
- Key 是否有权访问目标模型
- 请求头是否使用 `Authorization: Bearer <key>`

### Key 过期

请创建新 Key 并更新客户端配置。
