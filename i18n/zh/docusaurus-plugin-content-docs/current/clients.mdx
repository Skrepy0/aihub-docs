# 客户端接入

AIhub 提供 OpenAI 兼容接口，支持任何允许自定义 API Base 的客户端接入。本页以 Claude Code、Codex、AnythingLLM 为例，说明具体配置方法。

AIhub 接口地址：

```text
https://aihub.skrepy.dpdns.org/
```

> 字段命名差异：Claude Code 使用 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_AUTH_TOKEN`；Codex、AnythingLLM等 OpenAI 兼容客户端使用 `OPENAI_BASE_URL` 和 `OPENAI_API_KEY`。下文按各客户端实际字段分别说明。

---

## 接入前准备

开始配置前，确认以下三项：

- 已在 AIhub 创建 API Key
- 已知当前可用的模型名（例如 `hy3`）
- 当前网络可访问 `https://aihub.skrepy.dpdns.org/`

不同客户端对配置项的命名存在差异，对应关系如下：

| 实际含义 | 常见字段名                                  |
| -------- | ------------------------------------------- |
| API Key  | API Key / Key / Token                       |
| Base URL | Base URL / API Base / Endpoint / Server URL |
| Model    | Model / Model Name / 模型名                 |

## Claude Code

Claude Code 通过环境变量或 `settings.json` 指定模型服务的地址与密钥。接入 AIhub 时，将请求指向 AIhub 并填入对应 Key。

### 配置文件位置

Claude Code 的 `settings.json` 有两个层级：

- **用户级**：对所有项目生效
  - Windows：`%USERPROFILE%\.claude\settings.json`
  - macOS / Linux：`~/.claude/settings.json`
- **项目级**：仅对当前项目生效
  - `<项目根目录>\.claude\settings.json`

实际路径举例（Windows）：

```text
C:\Users\你的用户名\.claude\settings.json
```

若文件不存在，新建一个 `settings.json` 即可。

### 打开配置文件

**方式一：文件管理器**

1. 打开资源管理器，进入 `C:\Users\你的用户名\.claude\`
2. 找到或新建 `settings.json`
3. 用 VS Code 或记事本打开

**方式二：命令行**

Windows（PowerShell）：

```powershell
notepad $env:USERPROFILE\.claude\settings.json
```

macOS / Linux：

```bash
code ~/.claude/settings.json
```

### 完整配置示例

以下是一个接入 AIhub 的完整 `settings.json`：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-xxxxxx",
    "ANTHROPIC_BASE_URL": "https://aihub.skrepy.dpdns.org",
    "ANTHROPIC_MODEL": "hy3",
    "ANTHROPIC_SMALL_FAST_MODEL": "hy3",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "hy3",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "hy3",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "hy3",
    "CLAUDE_CODE_SUBAGENT_MODEL": "hy3",
    "CLAUDE_CODE_MAX_OUTPUT_TOKENS": "81929",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  },
  "permissions": {
    "allow": ["Bash(curl -X GET \"http://localhost:3000/api/test\")"],
    "deny": []
  },
  "enabledPlugins": {
    "frontend-design@claude-plugins-official": true
  }
}
```

### 配置项说明

**`env` 中的模型相关变量**

| 变量                             | 作用                        | 示例                             |
| -------------------------------- | --------------------------- | -------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`           | AIhub API Key，用于鉴权     | `sk-xxxxxx`                      |
| `ANTHROPIC_BASE_URL`             | 请求发送地址，填 AIhub 接口 | `https://aihub.skrepy.dpdns.org` |
| `ANTHROPIC_MODEL`                | 默认模型                    | `hy3`                            |
| `ANTHROPIC_SMALL_FAST_MODEL`     | 轻量/快速任务使用的模型     | `hy3`                            |
| `ANTHROPIC_DEFAULT_SONNET_MODEL` | Sonnet 档位模型             | `hy3`                            |
| `ANTHROPIC_DEFAULT_OPUS_MODEL`   | Opus 档位模型               | `hy3`                            |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL`  | Haiku 档位模型              | `hy3`                            |
| `CLAUDE_CODE_SUBAGENT_MODEL`     | 子代理使用的模型            | `hy3`                            |

> 若仅接入 AIhub，不要求将所有档位变量填为同一值；但统一指向一个可用模型，可避免 Claude Code 在调用特定档位模型时因找不到模型而报错。

**其它运行参数**

| 变量                                       | 作用                             | 示例    |
| ------------------------------------------ | -------------------------------- | ------- |
| `CLAUDE_CODE_MAX_OUTPUT_TOKENS`            | 单次回复的最大输出 token 数      | `81929` |
| `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` | 关闭非必要网络请求，`1` 表示开启 | `1`     |

**顶层配置项**

| 配置项              | 作用                                |
| ------------------- | ----------------------------------- |
| `env`               | 注入到 Claude Code 运行时的环境变量 |
| `permissions.allow` | 允许自动执行的命令白名单            |
| `permissions.deny`  | 禁止执行的命令列表                  |
| `enabledPlugins`    | 已启用插件的开关                    |

### 最小可用配置

若仅需验证连通性，以下配置即可：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-xxxxxx",
    "ANTHROPIC_BASE_URL": "https://aihub.skrepy.dpdns.org",
    "ANTHROPIC_MODEL": "hy3"
  }
}
```

未单独指定档位模型时，Claude Code 会回退使用 `ANTHROPIC_MODEL`。

### 通过系统环境变量配置

也可直接在终端设置环境变量，无需修改配置文件：

Windows（PowerShell）：

```powershell
$env:ANTHROPIC_AUTH_TOKEN = "sk-xxxxxx"
$env:ANTHROPIC_BASE_URL = "https://aihub.skrepy.dpdns.org"
$env:ANTHROPIC_MODEL = "hy3"
```

macOS / Linux：

```bash
export ANTHROPIC_AUTH_TOKEN=sk-xxxxxx
export ANTHROPIC_BASE_URL=https://aihub.skrepy.dpdns.org
export ANTHROPIC_MODEL=hy3
```

> 环境变量 `ANTHROPIC_AUTH_TOKEN` 和 `ANTHROPIC_BASE_URL` 的优先级高于 `settings.json` 中的配置。

### 配置步骤

1. 打开 `settings.json`
2. 在 `env` 中填入 `ANTHROPIC_AUTH_TOKEN`
3. 在 `env` 中填入 `ANTHROPIC_BASE_URL`
4. 在 `env` 中填入 `ANTHROPIC_MODEL`
5. 保存文件并重启 Claude Code
6. 发送一条消息验证

### 常见问题

**连接失败**

依次排查：

- `settings.json` 是否为合法 JSON
- `ANTHROPIC_BASE_URL` 是否包含多余空格或漏写 `https://`
- `ANTHROPIC_AUTH_TOKEN` 是否完整复制
- 修改后是否重启 Claude Code
- 网络是否可访问 `https://aihub.skrepy.dpdns.org`

**提示 JSON 格式错误**

多为多余逗号、缺失引号或不匹配的大括号导致。先退回到最小配置，再逐步补充。

**保存配置后无法正常对话**

多为模型名不可用、AIhub 未开放对应模型，或请求实际未经过 AIhub。可用 curl 验证接口本身是否正常。

## Codex

首先下载一个CodexApp的增强工具:[Codex++](https://codexpp.cc)
下载并安装后, 启动Codex++ 管理工具.

在左侧侧边栏选择"供应商配置", 然后添加供应商.

## AnythingLLM

AnythingLLM 支持通过 `Generic OpenAI` provider 接入自定义 OpenAI 兼容服务。

### 配置步骤

1. 打开 AnythingLLM 应用（Desktop 或 Docker）
2. 进入 设置 → 人工智能供应商 → 大语言模型(LLM)
3. 在 LLM provider 搜索框中输入 `Generic OpenAI` 并选择
4. 填入 Base URL
5. 填入 API Key
6. 填入 Chat Model Name
7. 根据需要设置 Token Context Window 和 Max Tokens
8. 保存配置
9. 新建 workspace，发送测试消息验证

### 填写项

<Picture url="/img/clients/AnythingLLM_config.webp" info="AnythingLLM 配置" />

- **LLM Provider**：选择 `Generic OpenAI`
- **Base URL**：`https://aihub.skrepy.dpdns.org/v1`
- **API Key**：AIhub 的 Key
- **Chat Model Name**：可用模型名（如 `hy3`）
- **Token Context Window**：根据模型限制设置（如 `16000`、`128000`）
- **Max Tokens**：按需配置（如 `1024`、`2048`）

> AnythingLLM 使用 `OPENAI_API_KEY` 字段，勿写成 `ANTHROPIC_*`。

### 排错

- Provider 是否选为 `Generic OpenAI`
- Base URL 是否完整（含 `/v1` 后缀）
- Model 是否可用
- 配置是否保存

## 通用配置原则

不同客户端配置的关键差异集中在两个方面：

**字段命名体系**：

- Anthropic 风格（Claude Code）：`ANTHROPIC_*` 前缀
- OpenAI 风格（Codex、AnythingLLM 上层工具）：`OPENAI_*` 前缀

配置前先确认客户端实际读取的字段名，避免混用。

**Base URL 格式**：

- 大部分 OpenAI 兼容客户端要求 Base URL 以 `/v1` 结尾
- 部分客户端（如 Claude Code）接受无后缀的根地址
- 若连接失败，尝试在 Base URL 末尾添加或移除 `/v1`

---

## 通用排查顺序

接入失败时，按以下顺序排查：

1. Key 是否正确
2. Base URL 是否为 `https://aihub.skrepy.dpdns.org/`（注意 `/v1` 后缀）
3. 模型名是否正确
4. 客户端是否支持 OpenAI 兼容接口
5. 配置是否已保存
6. 是否存在网络访问限制
